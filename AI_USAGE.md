# My AI Usage

AI tools have supported work on this project with planning, implementation ideas, test design, debugging and documentation. [PROMPTS.md](PROMPTS.md) lists the public conversation links available in this checkout and identifies additional source records that are not present. No missing conversation is reconstructed.

Earlier project documentation names ChatGPT and records AI assistance with repository setup and fixes. It also reports Amazon Q planning assistance and Gemini UI ideas. These historical disclosures are retained, but their source conversations are not all available here.

AI-assisted changes should be checked against the code, tests and actual application behavior. [TEST_REPORT.md](TEST_REPORT.md) records observed test, lint and build results and their limits. Automated checks run by an AI assistant should not be described as personally run by the project owner.

AI-assisted commits carry the appropriate co-author trailer where it was added. Some historical AI-assisted commits predate the trailer requirement and were not amended. See the repository history audit for the recorded exceptions.
