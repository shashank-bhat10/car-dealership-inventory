# 🤖 My AI Usage

AI tools were used throughout the development of the **Car Dealership Inventory Management System** as development and learning assistants. They were mainly used for planning, understanding technical concepts, generating UI ideas, debugging, testing, and improving project documentation.

## 🧠 Amazon Q

**Amazon Q** was used primarily during the planning and implementation stages of the project.

It was used for:

- Creating the overall **implementation plan** for the project.
- Breaking the project into manageable **development phases**.
- Planning the sequence of frontend and backend implementation tasks.
- Providing guidance on the development approach for different features.
- Structuring implementation steps before starting development.
- Helping identify the components and functionality required for each phase.

## 🎨 Gemini

**Gemini** was mainly used for **UI planning and design assistance**.

It was used for:

- Creating UI prompts based on the implementation plan.
- Generating ideas for the frontend layout and visual design.
- Suggesting improvements to the user interface and user experience.
- Helping plan responsive and user-friendly frontend components.
- Providing design ideas for vehicle listing, vehicle details, forms, filters, navigation, and other UI elements.

## 💬 ChatGPT

AI assistance from **ChatGPT** was used throughout the development process for technical guidance, debugging, testing, documentation, and learning.

### 📋 Project Planning

- Understanding project requirements and deliverables.
- Breaking the project into development phases.
- Reviewing progress at the end of each phase.
- Identifying remaining implementation and testing tasks.
- Reviewing whether project requirements were completed.

### ⚙️ Backend Development

- FastAPI project setup guidance.
- PostgreSQL database connection setup.
- Database schema and model design guidance.
- REST API design and implementation guidance.
- CRUD operation implementation guidance.
- Authentication and JWT implementation guidance.
- User registration and login flow guidance.
- Protected API endpoint implementation.
- Role-based authorization guidance.
- Request validation and error-handling guidance.

### ⚛️ Frontend Development

- React and Vite project setup guidance.
- Component structure and page organization.
- React routing and navigation guidance.
- Authentication flow implementation.
- JWT token handling on the frontend.
- API service and backend integration guidance.
- Vehicle listing and vehicle detail page development.
- Search and category filtering functionality.
- Inventory management UI.
- Add, update, delete, purchase, and restock functionality.
- Authorization-based UI behavior.
- UI layout and styling improvements.

### 🐛 Debugging and Troubleshooting

ChatGPT was also used to diagnose and resolve development issues, including:

- Frontend rendering problems.
- Backend API errors.
- Authentication and authorization issues.
- JWT and token-related problems.

- API request and response errors.

## 🔍 Role of AI in the Project

AI tools were used as **development and learning assistants**, rather than as a replacement for the development process.

AI assistance was used to provide suggestions, explanations, implementation guidance, debugging support, testing guidance, UI ideas, and documentation assistance. The actual project implementation, code integration, testing, debugging, verification, and final decisions were performed during the development process.

AI-generated suggestions were reviewed, adapted, tested, and integrated according to the project's requirements.
